# Roadmap

MCP Bridge is a spare-time open-source project. This page describes areas that may be improved; it is not a delivery schedule or a promise of support.

## Near-term priorities

- Publish a clean, reproducible source tree and a first public Windows release.
- Add clear screenshots and setup documentation.
- Document the supported server configuration formats and current limitations.
- Improve automated checks for builds and core server lifecycle behaviour.

## Longer-term ideas

- Broader compatibility testing with MCP clients and server implementations.
- More diagnostics for common server startup and connection problems.
- Additional documentation and examples from community use.

Suggestions and focused contributions are welcome through GitHub Issues.
